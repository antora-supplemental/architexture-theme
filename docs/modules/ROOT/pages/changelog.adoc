== [0.1.2] - 2026-10-24

=== Changed

* Theme switch hex reveal: tiles twice as large (hex radius 45px to 90px) and 25% faster (tile 0.5s to 0.375s, stagger 0-0.7s to 0-0.525s, view transition 1.2s to 0.9s, color swap 0.4s to 0.3s).
* Footer: removed the external design-parity note.

* Distribution: GitHub Releases ship `ui-bundle.zip` only; npm deprecated. See the guide module npm deprecation page.

== [0.1.0] - 2026-04-11

=== Added

* **Aesthetic Engine**: Initial implementation of the "Stone and Graphite" theme logic.
* **Tailwind v4 Integration**: Migration to Tailwind v4 CSS pipeline.
* **Structural Reveal**: Hardware-accelerated hexagonal View Transition for theme switching.
* **Antora Supplemental UI**: Partial overrides for header, head, and footer scripts to support the architectural theme.
